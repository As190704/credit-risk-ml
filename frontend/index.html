Top Contributing Features

◐

Calibrated

Predicted probabilities are calibrated against held-out data, so "70%" behaves like 70%, not an arbitrary model score.

▤

Threshold, not guesswork

The line between risk classes is chosen deliberately and documented — never silently defaulted to 0.5.

◫

Explainable

Every assessment can show which features moved the model's output, and by how much — association, not causation.
